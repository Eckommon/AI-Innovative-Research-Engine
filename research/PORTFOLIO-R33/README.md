## Frozen Mission-ROI rubric / 고정 평가틀

Reuse the established nine dimensions, each scored 0–5, total /45:

1. Mission bottleneck

### R33 interpretation rule

`Zero-cost operability` and `Next-gate information gain` must reflect **current executable public-source access**, not merely documentation that a source theoretically exists.

`Low overlap / novelty risk` is conservative: a directly similar published design or agency-operational use materially reduces the score. Search absence is not novelty proof.

## Frozen tie-break / 동점 규칙

1. next-gate information gain;
2. low overlap / novelty risk;
3. join defensibility;
4. zero-cost operability;
5. direct outcome;
6. still tied → fail closed with no selection.
