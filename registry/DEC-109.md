# DEC-109 — Stop Before US-GRID-E01 Numerical Preregistration and Return to Stage 0
# DEC-109 — US-GRID-E01 수치 사전등록 전 중단 및 Stage 0 복귀

## Decision / 결정

Do **not** create or execute an outcome-bearing `US-GRID-E01` from the current BA-year design.

Apply:

**`HOLD_US_GRID_E01_CROSS_BA_SUPPORT_TOO_SPARSE__RETURN_TO_PORTFOLIO`**

This is **not** a reversal of `US-GRID-F01` PASS.

## Why stop / 중단 이유

`DEC-108` authorized outcome-blind E01 preregistration only if one defensible low-degree-of-freedom design could be frozen without forcing the data.

A prospective design based on:
- pre-entry EIA operating state;
- BA × queue-entry-year independent cells;
- >=3 completed projects per cell;
- >=2 qualifying years per BA;

produces only:
- ERCO 2021: 45 projects;
- ERCO 2022: 17 projects;
- ERCO 2023: 29 projects.

Thus the final independent structure is **3 cells from one BA**.

Loosening the project-per-cell threshold, dropping the multi-year BA rule, switching to project-level pseudo-replication, selecting only ERCO, or trying several EIA predictors would be a structural rescue rather than the intended replicated cross-BA experiment.

## Mission-ROI application / 목적-ROI 적용

Under `MEM-054`, continuing this branch would now mainly optimize a technically possible descendant instead of maximizing new cross-dataset scientific information.

Preserve:
- F01 PASS;
- 41-entity deterministic identity bridge;
- exact LBNL/EBA snapshots;
- IR→COD source semantics;
- 447-project completed structural asset.

Do not discard these assets. Revisit only if:
- a later LBNL edition adds enough completed projects across multiple BAs/years;
- a distinct prospectively justified independent-unit design becomes available;
- the user explicitly prioritizes a one-BA or survival-model branch.

## Exact next action / 정확한 다음 행동

Return to mandatory Stage 0 portfolio review and re-rank preserved candidates.

The previous R04 second-place candidate `C-EU-001 Cross-National Grid Stress` should enter the review as the leading fallback, but selection must be made by the portfolio review rather than automatically.
