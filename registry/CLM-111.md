# CLM-111 — Independent RHF Experiment Supports Lower Melt-Pool-Area Variability
# CLM-111 — 독립 RHF 실험의 Melt-Pool-Area 변동성 감소 지지

## Claim / 주장

In NIST `mds2-2507` v1.0.1, using physical part as the independent unit and the preregistered non-selective comparison, the 50 RHF variable-power parts show lower median part-level melt-pool-area variability than the five constant-power baseline parts.

Frozen result:
- 55/55 physical parts valid, 1,498 rows each;
- baseline median part-level area SD > RHF median part-level area SD;
- one-sided 100,000 label-permutation add-one `p = 0.0124798752012`;
- all 5/5 frozen index blocks support the same reduction direction;
- gate `PASS_E36_EXTERNAL_RHF_VARIABILITY_REDUCTION`.

Length sensitivity supports the same direction in 5/5 blocks; width supports it in 4/5 blocks.

## Unit semantic boundary / 단위 경계

Per `AMENDMENT-02`, exact stored units of the headerless analysis CSV values are not overclaimed. Durable interpretation uses **source-scale area/length/width numeric units**. The direction, permutation inference, block signs and percentage comparisons are invariant to a common positive linear unit conversion.

## Exposure / 노출

Publication-level RHF direction and optimized reduction were known before E36. This is confirmatory/reproduction evidence, not pristine outcome-blind discovery.

## Not claimed / 비주장

- not randomized causal proof;
- not proof every RHF parameter setting is superior;
- not same-construct replication of E33;
- not cross-machine/material universality;
- no row/frame pseudo-replication.
