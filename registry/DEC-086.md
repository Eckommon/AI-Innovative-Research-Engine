# DEC-086 — Exact E43 Rerun After Verified Pre-Performance Download Timeout
# DEC-086 — 성능실행 전 Download Timeout 확인 후 E43 동일 재실행

## Decision / 결정

Classify historical E43 run `32648786267` as an execution-harness/source-download failure before simulator performance. The failure occurred in F42 input reconstruction while reading the checksum-frozen NIST source and terminated with `TimeoutError: The read operation timed out`.

Authorize one **exact failed-job rerun** before changing any network or experiment parameter.

## Invariants / 불변조건

The rerun must retain DEC-085 unchanged:
- exact NIST source/checksum and F42 N0/R1 path hashes;
- pinned 3DThesis commit;
- source-grounded P01 transfer;
- timestep/domain/resolution/material/beam/output;
- per-case 480 s runtime cap and 20 min workflow cap;
- spatial positive `MP_width` CV endpoint;
- frozen PASS/PARTIAL/NO/HOLD thresholds;
- no outcome-based rescue or retuning.

## Escalation rule / 후속 규칙

If the exact rerun again fails at NIST download, only bounded download retry/read-timeout hardening may be considered in a new amendment. No scientific or simulator parameter may be changed to address a network failure.
