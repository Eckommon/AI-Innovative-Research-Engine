# DEC-022 — Adopt RAW_DATA_TRANSIENT_ONLY / 원천데이터 일시 처리 원칙 채택

**KO:** 프로젝트의 외부 공개 raw-data 기본 처리방식을 `RAW_DATA_TRANSIENT_ONLY`로 채택한다. 원천데이터는 권위 원천에 두고, 필요 시 zero-cost 실행환경에 일시 다운로드하여 exact version/checksum 검증 후 분석하고 실행 종료 시 폐기한다. GitHub에는 provenance·checksum·분석코드·무결성 inventory·derived result만 남긴다. raw source bytes 또는 raw-data Actions artifact의 영구 저장은 기본 금지한다.

**EN:** Adopt `RAW_DATA_TRANSIENT_ONLY` as the project-wide default for external public raw data. Keep source bytes at the authoritative provider; when needed, download them transiently into a zero-cost execution environment, verify exact version/checksum, analyze them, and discard them at teardown. Persist only provenance, checksums, deterministic code, integrity inventories, and derived results. Permanent repository or Actions-artifact storage of raw source bytes is prohibited by default.
