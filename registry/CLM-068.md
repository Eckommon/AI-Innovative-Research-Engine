# CLM-068 — Authoritative X16 Semantics Support a Frozen Deterministic Part-Segmentation Rule
# CLM-068 — authoritative X16 의미론이 결정론적 part segmentation 규칙 고정을 지지

**Claim / 주장:** NIST X16 User Notes establish the layer-125 4×4 part-label topology and 10 µs XYPT/DAQ organization, while NIST AMMT XYPT/DAQ semantics establish commanded XY/power and actual Galvo XY/power-reference roles. These facts are sufficient to freeze, before numerical outcome access, a deterministic `k=16` layer-125 XYPT command-space clustering + official-topology label mapping + centroid-Voronoi DAQ assignment rule without digitizing numeric boundaries from Figure 1. / NIST X16 User Notes의 layer-125 4×4 part-label topology와 10 µs XYPT/DAQ 구조, 그리고 NIST AMMT의 command/actual XY·power semantics는 수치 outcome 접근 전에 Figure 1의 숫자 경계를 digitize하지 않고 deterministic `k=16` XYPT clustering + 공식 topology label mapping + centroid-Voronoi DAQ assignment 규칙을 고정하기에 충분하다.

**Evidence class / 근거 등급:** `OBSERVED_PRIMARY + FROZEN_METHOD`.

**Boundary / 경계:** The rule is frozen but not numerically validated on retrieved XYPT bytes. Future validation failure must HOLD rather than retune the rule. / 규칙은 고정됐지만 retrieved XYPT bytes에서 수치 검증된 것은 아니며 향후 검증 실패 시 retuning이 아니라 HOLD한다.
