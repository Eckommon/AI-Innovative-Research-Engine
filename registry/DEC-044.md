# DEC-044 — Finalize F19 as PARTIAL_F19_SEGMENTATION_RULE_READY
# DEC-044 — F19를 PARTIAL_F19_SEGMENTATION_RULE_READY로 종료

**Decision / 결정:** Finalize `AMBENCH-F19` as **`PARTIAL_F19_SEGMENTATION_RULE_READY`**. Preserve the preregistered layer-125 deterministic `k=16` XYPT command-space segmentation/topology/Voronoi rule unchanged, but do not start E19 until the exact authoritative XCT histogram workbook is byte/checksum/schema-qualified and the frozen segmentation rule is actually validated on authoritative XYPT bytes. / `AMBENCH-F19`를 **`PARTIAL_F19_SEGMENTATION_RULE_READY`**로 종료한다. layer-125 deterministic `k=16` XYPT command-space segmentation/topology/Voronoi 규칙은 변경 없이 보존하되, exact authoritative XCT histogram workbook의 byte/checksum/schema qualification과 frozen segmentation의 authoritative XYPT byte 검증이 모두 완료되기 전 E19을 시작하지 않는다.

**Rationale / 근거:** Authoritative NIST topology and XYPT/DAQ semantics resolve the conceptual part-segmentation method without outcome tuning or numeric figure digitization. The remaining bottleneck is source execution: the small XCT workbook/checksum remains inaccessible through current verified zero-cost paths. / NIST 공식 topology와 XYPT/DAQ semantics로 outcome tuning·그림 숫자 digitization 없이 conceptual segmentation 방법을 고정할 수 있으나, XCT workbook/checksum의 현 0원 경로 접근이 여전히 차단되어 source execution bottleneck이 남는다.

**Prohibitions / 금지:** No MPM rescue, alternate layer group, TIFF/STL rescue, manual cluster relabeling, outcome-aware segmentation change, or high-capacity model. / MPM rescue·다른 layer group·TIFF/STL rescue·수동 cluster relabeling·outcome-aware segmentation 변경·고용량 모델을 금지한다.

**Cost / 비용:** No paid/potentially paid route used; prior explicit approval remains mandatory for any such route. / 유료·잠재유료 경로는 사용하지 않았으며 해당 경로는 사전 명시승인을 계속 요구한다.
