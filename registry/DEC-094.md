# DEC-094 — Select C-KR-003 Port Weakest-Link as Next Mission Branch
# DEC-094 — C-KR-003 항만 최약고리 후보를 다음 Mission Branch로 선정

## Decision / 결정

Complete `PORTFOLIO-R01` with **`C-KR-003 Port Weakest-Link Intelligence / 항만 최약고리 지능화`** as the next primary scientific branch.

The exact next action is a separately preregistered **`KR-PORT-F01 — Port-Call Identity & Turnaround-Target Feasibility Gate`**.

## Why selected / 선정 이유

Under `MEM-054 / DEC-093`, C-KR-003 provides the best current balance of:
- high existing Combination IPS (`95/100`);
- cross-dataset relationship value;
- event-level operational resolution;
- direct persistent-bottleneck relevance;
- clear falsifiable next uncertainty;
- low immediate compute/data burden;
- practical logistics/port-operation utility;
- minimal infrastructure-recursion risk.

The next uncertainty is scientific/semantic rather than tooling: whether official port-call records support one deterministic event identity and a defensible operational turnaround/delay target across vessel movement, facility-use, cargo/container and weather contexts.

## Current official-source check / 현행 공식 source 확인

Minimal current verification on 2026-09-03 found:
- Public Data Portal vessel-operation / vessel-entry metadata continues to describe port, call sign, arrival count and arrival/departure time semantics;
- Ministry of Oceans and Fisheries `항만시설사용정보` remains a free, real-time REST API with automatic approval, querying by `prtAgCd + etryptYear + etryptCo + clsgn` and returning those identifiers plus berth/mooring-place fields and `etryndDt`;
- KMA ASOS hourly observations remain a free REST JSON/XML API suitable for time-based physical-weather context.

## KR-PORT-F01 boundary / KR-PORT-F01 경계

KR-PORT-F01 must remain a feasibility/source-semantic gate. Before any large history extraction or predictive model, freeze and verify:
1. source identities/access/licensing;
2. candidate port-call key semantics;
3. duplicate/correction/update rules;
4. deterministic arrival/departure target construction and nonnegative-duration validity;
5. facility-use attachment without leakage;
6. weather join semantics;
7. bounded free sample-access route;
8. downstream target hierarchy only if PASS.

No model training is authorized by this decision.
