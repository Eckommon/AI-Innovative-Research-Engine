# DEC-042 — Finalize F18 as PARTIAL; do not start E19 yet
# DEC-042 — F18을 PARTIAL로 종료하고 E19는 아직 시작하지 않는다

**Decision / 결정**

Finalize `AMBENCH-F18` as **`PARTIAL_MANAGEABLE_X16_ROUTE_READY`**. Do not start numerical process↔XCT modeling until both blockers are separately resolved: (1) authoritative retrieval/checksum/schema qualification of `OverhangX16_ImageHistograms.xlsx`, and (2) deterministic authoritative X16 part-coordinate segmentation for the frozen DAQ/XYPT representation. / F18을 `PARTIAL_MANAGEABLE_X16_ROUTE_READY`로 확정하고 XCT workbook의 authoritative byte/checksum/schema와 DAQ/XYPT의 exact part-coordinate segmentation이 모두 해결되기 전 E19 수치 실험을 시작하지 않는다.

**Rationale / 근거**
The route is practical and physically meaningful, but the selected bytes/checksums and exact 16-part segmentation rule remain unverified. Expanding data volume or changing layer groups would be post-hoc rescue rather than evidence acquisition. / 경로는 실용적이고 물리적으로 의미 있으나 selected bytes/checksum과 exact part segmentation이 미검증이며, data volume 확대는 증거획득이 아닌 사후 rescue가 된다.
