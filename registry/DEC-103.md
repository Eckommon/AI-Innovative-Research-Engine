# DEC-103 — Close US-PORT-F01 as HOLD and return to Stage 0
# DEC-103 — US-PORT-F01을 HOLD로 종결하고 Stage 0로 복귀

## Decision / 결정

Finalize `US-PORT-F01` as:

**`HOLD_US_PORT_PUBLIC_JOIN_ROUTE`**.

The exact `C-US-002` BTS dwell × NOAA weather route is not authorized to proceed to an effect experiment.

Return immediately to mandatory Stage 0 Mission-ROI portfolio selection.

## Basis / 근거

F01 found:

1. **BTS public machine-readable outcome — blocking**
   - official Socrata dwell datasets are accessible and time-indexed;
   - metadata-only discovery found no relevant dataset exposing `port identity + time + dwell` together;
   - `abu9-jbyq` and `nfsh-p62e` expose only time fields plus `Hours`, without port or call/support fields.

2. **Port geography — source-ready**
   - BTS/USACE provide nationally consistent port definitions and machine-readable NTAD Port Area / Port Statistical Area geography.

3. **NOAA Storm Events — source-ready**
   - official bulk files expose date/time, county/zone/marine semantics, FIPS/name fields and begin/end coordinates where applicable, with event IDs and creation-date versioning.

4. **Overlap — insufficient for a valid port-time panel**
   - 2019–June 2023 temporal overlap exists;
   - a deterministic port-time outcome panel does not, because the public machine-readable BTS dwell assets inspected lack port identity.

Under the preregistered gate, this is HOLD rather than PASS/PARTIAL.

## Prohibited rescue / 금지된 구제

Do **not**:
- scrape or reverse engineer interactive BTS Port Profiles/dashboard values;
- manually transcribe individual-port dwell values;
- invent a port mapping from aggregate national/top-port dwell series;
- replace the outcome after inspecting weather-effect performance;
- create a tooling descendant solely to bypass the public-source limitation.

The branch may be reconsidered only when a new stable official machine-readable port-level dwell/berthing source becomes available or after a separately selected Stage 0 candidate reframes the outcome before effect exposure.

## Preserved reusable assets / 보존 자산

The following remain reusable independently of this HOLD:
- official BTS/USACE port geography semantics;
- NOAA Storm Events bulk schema and versioning route;
- bounded Socrata metadata-discovery workflow pattern, remaining `SHARED-INTERNAL-CANDIDATE` only.

No workflow is promoted to Skill/MCP/Plugin by this decision.

## Exact next action / 정확한 다음 행동

Open `PORTFOLIO-R03` and re-rank remaining mission candidates using current source accessibility, direct bottleneck outcome quality, cross-dataset value, falsifiability, practical utility, and zero-cost feasibility.

Do not automatically select the next candidate merely because it was previously ranked second.

## Cost / 비용
