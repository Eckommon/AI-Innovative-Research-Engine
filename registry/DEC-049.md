# DEC-049 — F22 establishes all-four immutable bytes but holds on headerless serialization schema
# DEC-049 — F22 4개 전체 불변 byte 확보, headerless serialization schema는 HOLD

**Decision / 결정:** `AMBENCH-F22` final descriptive gate = **`PARTIAL_F22_ALL_FOUR_IMMUTABLE_BYTES_READY__SCHEMA_HEADER_HOLD`**.

**KO:** `mds2-3761`의 네 ZIP은 모두 current NIST NERDm exact component identity·SHA-256·official URL이 확립됐고 local transient retrieval hash가 정확히 일치한다. 각 archive는 valid하며 250개 CSV와 `L0001`–`L0250` exact layer coverage를 재현한다. 따라서 F15/F16의 source-byte integrity 병목은 해소된 것으로 본다.

그러나 original F22 full PASS는 textual 40-column header를 요구했고 실제 CSV는 headerless였다. 또한 Part 1 header-assumption 오류로 제한적 numerical pre-exposure가 발생했다. 따라서 original full PASS를 소급적으로 약화하거나 통과 처리하지 않는다. Modeling은 계속 금지하고, 다음 단계는 별도 preregistered headerless serialization/schema mapping gate다. 이후 모든 numerical experiment는 `VIOLATED_LIMITED` pre-exposure를 명시해야 한다.

**EN:** All four `mds2-3761` ZIPs now have current NIST NERDm exact component identities, SHA-256 hashes, official URLs, and exact matching local transient-retrieval hashes. Each archive is valid and reproduces 250 CSV files with exact `L0001`–`L0250` layer coverage. The F15/F16 source-byte integrity blocker is therefore considered resolved.

However, the original F22 full PASS required a textual 40-column header and the actual CSVs are headerless. A Part 1 header-assumption error also caused limited numerical pre-exposure. Do not retroactively weaken or pass the original full gate. Modeling remains prohibited. The next step is a separately preregistered headerless serialization/schema mapping gate, and any later numerical experiment must disclose the `VIOLATED_LIMITED` pre-exposure.
