## Mission-ROI comparison / 목적-ROI 비교

### C-EU-001 Cross-National Grid Stress
High scientific value, but current ENTSO-E automated access requires account/token provisioning. Keep `HOLD_READY_SECONDARY` rather than create an access/credential descendant.

### C-EU-004 Industrial Site Climate Risk — SELECT
Strong because:
- EEA Industrial Reporting ver.16.0 (20 Feb 2026) is an official direct-download spatial/tabular facility dataset covering 2007–2024;
- the Industrial Emissions Portal exposes stable site/facility identifiers, reporting years, activities and spatial geometry semantics;
- NASA POWER provides a free global point API for daily/hourly meteorological variables with explicit UTC/LST time standards and direct URL requests;
- the next uncertainty is scientific/semantic joinability, not credential or transport engineering;
- facility-coordinate × climate-exposure relationships support cross-agency, cross-national stress testing with low initial compute burden.

### C-US-003 Critical Mineral Resilience
High value, but the initially intended Census trade API now requires an API key. Keep `HOLD_READY_SECONDARY`; do not create a credential-acquisition branch.

### Wave 2 Japan/UK/Singapore
Still valuable for breadth and L4/L5 progression, but current expected information gain is lower than testing one already-qualified high-IPS cross-dataset relationship with immediately public source routes. Keep `READY_AFTER_EU_ISR_F01`.

## Climate-source route / 기후 source 경로

The original Wave 1 candidate mentioned ERA5/Copernicus hazards. Current official CDS/ARCO documentation requires a CDS API key. To avoid reproducing an authentication bottleneck, select **NASA POWER** prospectively at the portfolio stage before any EU-ISR experiment or outcome inspection.

This is not a post-outcome source substitution. No facility-level climate association, ranking, threshold or model result has been inspected.

Initial climate variables must remain low-DOF and source-justified. F01 may inspect only schema/access/join semantics; no facility risk score is authorized.

## Branch-stop / Branch 중단

If `EU-ISR-F01` cannot demonstrate a reproducible zero-cost facility-coordinate→climate point/time join without speculative identity/spatial assumptions, close it HOLD/REJECT and return directly to Stage 0.

If PASS, authorize at most one separately preregistered controlled experiment before another mandatory Mission-ROI review.
