# CLM-123 — Current public BTS machine-readable dwell assets do not expose port identity
# CLM-123 — 현행 BTS 공개 기계판독 dwell 자산에는 port identity가 노출되지 않음

## Claim / 주장

**KO:** 2026-09-04 기준 BTS 공식 Socrata 카탈로그에서 `vessel dwell`, `vessel berthing`, `container vessel dwell`, `tanker vessel dwell`, `port dwell time`을 metadata-only로 탐색한 결과, 관련 dataset-type 자산 중 `abu9-jbyq`와 `nfsh-p62e`는 시간과 dwell metric은 제공하지만 port 식별자와 call/support field를 제공하지 않는다. 따라서 현재 확인된 공개 machine-readable BTS 자산만으로는 deterministic `port × time × dwell` panel을 만들 수 없다.

**EN:** As of 2026-09-04, a metadata-only search of the official BTS Socrata catalog for `vessel dwell`, `vessel berthing`, `container vessel dwell`, `tanker vessel dwell`, and `port dwell time` found that the relevant dwell datasets `abu9-jbyq` and `nfsh-p62e` expose time and a dwell metric but no port identifier or call/support field. Therefore the currently identified public machine-readable BTS assets cannot form a deterministic `port × time × dwell` panel.

## Evidence / 증거

- `research/US-PORT-F01/BTS_ASSET_DISCOVERY.md`
  - five catalog responses returned HTTP 200 and were SHA-256 pinned;
  - `abu9-jbyq`: `Month`, `Year`, `Hours`, `Quarter`, `Q-Year`, `Month-Year`; no port field;
  - `nfsh-p62e`: same six-column schema; no port field;
  - discovered machine-readable port-time dwell dataset IDs: `[]`.
- `research/US-PORT-F01/BTS_SCHEMA_PREFLIGHT.md`
  - public Socrata resource endpoint accessible;
  - 54 rows for the January 2019–June 2023 tanker asset;
  - bounded identity sample exposed time keys but no port identity.
- BTS technical documentation states dwell is calculated within defined port/terminal geofences and individual-port values are surfaced in Port Profiles, but F01 did not identify a stable tabular public export for those port-level dwell values.

## Boundary / 경계

This claim does **not** assert that BTS lacks underlying port-level dwell observations. It asserts only that the bounded official public machine-readable discovery route used by F01 did not expose a deterministic port-level dwell table.

It does not evaluate whether weather affects dwell time.
