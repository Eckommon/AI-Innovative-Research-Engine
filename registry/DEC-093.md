# DEC-093 — Adopt Mission Anchor and Portfolio Branch-Stop Control
# DEC-093 — 목적 고정 및 Portfolio Branch-Stop 통제 채택

## Decision / 결정

Adopt `MEM-054 — Mission Anchor & Branch-Stop Memory` as a mandatory durable project control.

The project shall optimize for **mission-level innovation/bottleneck discovery from relationships among public/research data**, not for completion of any particular dataset, experiment, simulator, or technical route.

## Supersession of F46 authorization / F46 승인 일부 철회

`DEC-092` remains authoritative for the historical F45 finalization, but its automatic authorization to proceed with AMBENCH-F46 is **superseded**.

AMBENCH-F46 is moved to:

**`DORMANT__NOT_ACTIVE__REQUIRES_REAUTHORIZATION`**.

No F46 Issue/workflow/download is authorized unless a future portfolio review establishes mission-level value or the user explicitly prioritizes finishing the P01/3DThesis branch.

## Mandatory Branch-Stop Review / 의무 Branch-Stop 검토

Before opening a descendant after HOLD/REJECT/runtime/source-access failure, record a `MISSION-ROI` check covering:
1. scientific uncertainty vs tooling uncertainty;
2. route dependency vs project-level necessity;
3. available higher-value alternatives;
4. consecutive infrastructure/runtime/source-transfer gates;
5. mission loss if the branch is stopped.

Default rule:

> **Two consecutive infrastructure/runtime/source-transfer descendants without new scientific evidence + credible alternative candidate → `HOLD_BRANCH / ARCHIVE_ROUTE → RETURN_TO_PORTFOLIO`.**

Continuation requires explicit justification under `MEM-054`.

## Portfolio reset / Portfolio 재정렬

The next active work should return to portfolio-level candidate selection rather than resume F46 automatically. Candidate selection shall prioritize Combination/Project IPS, cross-dataset/cross-agency/cross-national value, falsifiability, practical utility, scalability, and zero-cost feasibility.

## Evidence standards / 증거 기준

This decision does **not** weaken source integrity, preregistration, anti-pseudoreplication, fail-closed evaluation, exposure disclosure, or negative-result preservation. It adds a higher-level stopping rule above those controls.

## Cost / 비용

`COST-001` remains mandatory. Incremental monetary cost remains `0 USD`; potentially billable work requires explicit prior user approval.
