# CLM-060 — Current X16 XCT identity is mds2-2514; AMMT-page pointer conflict preserved
# CLM-060 — 현행 X16 XCT identity는 mds2-2514이며 AMMT page 충돌은 보존

**Claim / 주장:** The NIST AMMT datasets summary page currently points the X16 XCT section to DOI `mds2-2309`, while current Data.gov XCT dataset-level metadata identifies the XCT asset itself as `ark:/88434/mds2-2514` / DOI `10.18434/mds2-2514` and explicitly states that it contains XCT measurements of the sixteen parts from in-situ `mds2-2309`. F17 therefore qualifies `mds2-2514` as the current XCT identity while preserving the AMMT-page pointer as a source conflict of unknown cause.

**Evidence class:** `OBSERVED / CONFLICT-DISPOSITION`
**Verification:** `V2_PRIMARY_VERIFIED_CONFLICT`
