# CLM-181 — NHTSA product identity is large, but frozen F01 lacks communication-time schema

Corrected Run `35043099657` establishes that the frozen NHTSA Manufacturer Communications CSVs contain **13,729** valid normalized product keys across **347** makes and intersect the frozen Safety Recall source on **8,263** exact normalized product keys. The recall source contains **40,700** product keys with **17** date years and full date parse support.

However, both prospectively frozen communication CSVs expose only `TSB/Document ID, Make, Model, Model Year, Concise Summary` and no communication/addition date field. The runner-side NHTSA catalog HTML also returns HTTP 403. Therefore the frozen F01 result is **`HOLD_US_NHTSA_MC_F01_SOURCE_SCHEMA_OR_IDENTITY`**. No recall outcome conditioned on communications was opened.
