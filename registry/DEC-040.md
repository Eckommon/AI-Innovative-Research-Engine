# DEC-040 — F17을 PARTIAL_X16_SOURCE_READY로 확정

**Decision / 결정:** Finalize `AMBENCH-F17` as **`PARTIAL_X16_SOURCE_READY`**. Prefer the original Overhang X16 pair over `mds2-3761` as the next process–structure source branch because the original in-situ/XCT datasets have explicit same-build identity and systematic checksum sidecars. However, do not start numerical modeling until a separately preregistered manageable-representation gate qualifies the exact small XCT summary semantics, checksum-verifiable selected source bytes, and a practical zero-cost in-situ representation.

Current XCT identity for downstream source qualification is `mds2-2514`; the NIST AMMT page's `mds2-2309` XCT pointer remains preserved as a source conflict of unknown cause.

The 16 X16 parts are within-build technical replicates, not independent process conditions. No high-capacity ML or process-condition generalization is authorized.

No paid/potentially paid route was used. Any such action requires explicit prior user approval.
