# CLM-099 — E29 found a strong preregistered directional plate-level overlap-depth signal / E29에서 강한 사전등록 방향성 plate-level overlap-depth 신호가 확인되었다

**KO:** 사전등록된 P1 plate-level reconstruction과 3-vs-3 exact inference에서 0.75 ms turnaround군의 평균 overlap depth가 5.0 ms군보다 `29.083049409 µm` 높았다. Exact one-sided label-permutation p-value는 `0.05`로 20개 allocation에서 가능한 최솟값이었고, plate-level rank-biserial effect는 `1.0`(9 wins, 0 losses, 0 ties)이었다. 여섯 plate 모두에서 공통으로 valid한 44 tracks에 대한 sensitivity에서도 `Delta_common = 29.083049409 µm`로 같은 방향이 유지되었다. Frozen gate는 `PASS_E29_STRONG_DIRECTIONAL_EFFECT`이다.

**EN:** Under the preregistered P1 plate-level reconstruction and exact 3-vs-3 inference, the 0.75 ms turnaround group had a mean overlap depth `29.083049409 µm` greater than the 5.0 ms group. The exact one-sided label-permutation p-value was `0.05`, the minimum attainable over 20 allocations, and the plate-level rank-biserial effect was `1.0` (9 wins, 0 losses, 0 ties). The sensitivity restricted to the 44 tracks valid in all six plates retained the same direction with `Delta_common = 29.083049409 µm`. The frozen gate is `PASS_E29_STRONG_DIRECTIONAL_EFFECT`.
