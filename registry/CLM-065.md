# CLM-065 — X16 DAQ/XYPT semantics are physically useful but exact part segmentation remains unqualified
# CLM-065 — X16 DAQ/XYPT는 물리적으로 유용하지만 exact part segmentation은 미확립

**Claim / 주장**

Authoritative X16 User Notes and the inherited NIST X4 data description establish that XYPT contains commanded scan path/power at 10 us intervals and DAQ contains actual Galvo X/Y, LTZ, and laser-power-reference channels at 100 kHz with calibration headers. This supports a future lower-volume actual-process representation. However, F18 has not yet established an exact authoritative numeric X/Y boundary rule assigning samples to each of the sixteen X16 parts. / 권위 문서는 DAQ/XYPT의 actual/command process 의미를 확립하지만 16개 part별 sample 배정을 위한 exact numeric spatial rule은 아직 확립되지 않았다.

**Evidence / 근거**
- NIST `OverhangX16_In-situData_UserNotes.pdf`;
- NIST JRES 125.027 X4 data description inherited by X16;
- `research/AMBENCH-F18/RESULT.md`.

**Boundary / 경계**
No part-level process values were computed. / part-level process 수치는 계산하지 않았다.
