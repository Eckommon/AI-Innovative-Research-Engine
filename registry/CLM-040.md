# CLM-040 — D11 Diagnostic Boundary / D11 진단 경계

**KO:** `AMBENCH-D11`은 NIST `mds2-3842` v1.0.3의 21개 BP4 dynamic-coupling waveform에서 case-vs-repeat 시간정보 구조를 진단하도록 사전등록됐으며, 8개 frozen descriptor, normalized-waveform variance, PCA를 사용한다. D11은 physical outcome utility·예측력·인과성을 검증하지 않으며, raw coupling은 E09에서 이미 관측됐으므로 full outcome-blind가 아니다.

**EN:** `AMBENCH-D11` is preregistered to diagnose case-versus-repeat temporal-information structure in the 21 BP4 dynamic-coupling waveforms from NIST `mds2-3842` v1.0.3 using eight frozen descriptors, normalized-waveform variance, and PCA. D11 does not test physical-outcome utility, predictive value, or causality, and is not fully outcome-blind because raw coupling was already observed in E09.

**Evidence:** `research/AMBENCH-D11/README.md`; `DEC-026`.
