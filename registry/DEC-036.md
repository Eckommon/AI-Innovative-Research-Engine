# DEC-036 — AMBENCH-F15를 `PARTIAL_REGISTERED_SCHEMA_READY`로 확정

## Decision / 결정

Finalize `AMBENCH-F15` as **`PARTIAL_REGISTERED_SCHEMA_READY`**. Preserve `mds2-3761` as the preferred next external process–structure validation asset, but require a narrow source-integrity/access gate before any numerical association or predictive experiment.

`AMBENCH-F15`를 **`PARTIAL_REGISTERED_SCHEMA_READY`**로 확정한다. `mds2-3761`을 우선 외부 process–structure 검증 자산으로 유지하되, 수치 association·prediction 전에 별도 source-integrity/access gate를 의무화한다.

## Rationale / 근거

Official NIST documentation establishes a deterministic registered hierarchy and distinct in-situ/ex-situ physical variables at point/layer/part level. The missing requirement is immutable component provenance and checksum-verifiable byte inventory in the current zero-cost execution context.

## Prohibitions / 금지

- no numerical modeling on `mds2-3761` yet;
- no inferring archive contents from the paper alone;
- no treating rows/layers/parts as independent replicates without separate preregistration;
- no paid retrieval without prior explicit user approval.
