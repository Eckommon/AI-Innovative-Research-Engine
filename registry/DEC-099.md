# DEC-099 — Close UK-GRID-F01 PASS and Prefer Boundary-Headroom Qualification Before Numerical Experiment
# DEC-099 — UK-GRID-F01 PASS 종결 및 수치 실험 전 Boundary-Headroom 검증 우선

## Decision / 결정

1. Close `UK-GRID-F01` as **`PASS_UK_GRID_DAILY_ALIGNMENT_READY`**.
2. Preserve `CLM-120` as a bounded reusable daily-join claim.
3. Do **not** immediately consume the one authorized low-DOF experiment on a generic national-demand / embedded-renewables association.
4. Open one source-semantic scientific qualification gate:
   **`UK-GRID-F02 — boundary headroom × thermal-cost identity/alignment qualification`**.

## Why / 이유

The F01 route proves that a daily national system-state join is mechanically feasible, but mechanical feasibility is not sufficient scientific justification for a model.

NESO also publishes a more direct bottleneck construct:
- `Day Ahead Constraint Flows and Limits` gives half-hourly forecast flow and maximum limit for named constraint boundaries;
- `Thermal Constraint Costs Data 26-27` gives daily outturn thermal-constraint cost for named constraint groups.

A future relationship of the form:

`boundary-specific day-ahead headroom/stress → same boundary's realized thermal-constraint cost`

is closer to the source-defined physical bottleneck than a generic GB-wide demand correlation. It therefore has higher mission-level information value under `MEM-054`.

## F02 boundary / F02 경계

F02 is **not** a predictive or association experiment and does not consume the one-experiment allowance from `DEC-098`.

F02 may inspect only:
- schema metadata;
- distinct non-numerical `Constraint Group` identifiers;
- source-level temporal coverage/cardinality needed to establish join semantics.

It must not retrieve or emit actual `Limit (MW)`, `Flow (MW)` or `Daily Cost (GBP)` observations.

If exact boundary identity cannot be established without speculative translation, close F02 HOLD/REJECT and return to Stage 0 rather than creating a mapping-workaround chain.

## Future experiment authorization boundary / 향후 실험 승인 경계

Only if F02 PASS may one separately preregistered low-DOF numerical experiment be considered. Before any numerical values are opened it must freeze:
- primary boundary/group scope;
- one headroom/stress definition;
- one primary daily thermal-cost outcome;
- group-day aggregation and repeated-group handling;
- evaluation/maturity window;
- correction/missingness handling;
- primary statistic and falsification/materiality rule.

After that single numerical experiment, mandatory Stage 0 Mission-ROI return applies.

## Cost / 비용

Incremental monetary cost remains **0 USD**.
