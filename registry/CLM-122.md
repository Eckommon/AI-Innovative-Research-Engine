# CLM-122 — Frozen SCOTEX window fails the preregistered 48-half-hour cardinality contract
# CLM-122 — 고정 SCOTEX 기간은 사전등록된 48 half-hour cardinality 계약을 충족하지 못함

## Claim / 주장

**KO:** 사전 고정된 `2026-04-01..2026-07-31` SCOTEX 기간에서 day-ahead 식별자 데이터는 122개 날짜를 모두 포함하지만 총 `5,846`행이며 날짜별 행 수 집합은 `[38, 48]`이다. 따라서 정확히 `122 × 48 = 5,856`행을 요구한 UK-GRID-E01 구조 계약을 충족하지 못한다. 같은 기간 SCOTEX thermal-cost 식별자는 정확히 122개 날짜/122개 행/날짜당 1행을 충족했다.

**EN:** In the frozen `2026-04-01..2026-07-31` SCOTEX window, the day-ahead identifier source contains all 122 calendar dates but only `5,846` rows, with per-date row counts in `[38, 48]`. It therefore fails the preregistered requirement of exactly `122 × 48 = 5,856` rows. The SCOTEX thermal-cost identifier source satisfied exactly 122 dates, 122 rows, and one row per date.
