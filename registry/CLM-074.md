# CLM-074 — X16 workbook A/B semantics are authoritative / X16 workbook A/B 의미론 확립

**KO:** SHA-256이 검증된 NIST `DataDescription_OverhangPartX16_XCT.pdf`는 `OverhangX16_ImageHistograms.xlsx`의 각 part sheet에서 첫 열이 histogram bin edges, 둘째 열이 각 bin의 voxel counts라고 명시한다. Histogram 축 의미는 X = 16-bit Digital Level, Y = Number of Voxels이며, histogram은 XCT TIFF image stack에서 ImageJ로 계산되었다.

**EN:** The SHA-256-verified NIST `DataDescription_OverhangPartX16_XCT.pdf` explicitly states that each part sheet in `OverhangX16_ImageHistograms.xlsx` uses the first column for histogram bin edges and the second for voxel counts within each bin. The histogram axes are X = 16-bit Digital Level and Y = Number of Voxels, and the histograms were calculated in ImageJ from XCT TIFF image stacks.
