# DEC-050 — F23 passes headerless 40-column semantic mapping gate / F23 headerless 40열 의미 매핑 gate PASS

**Decision / 결정:** `AMBENCH-F23` final gate = **`PASS_F23_HEADERLESS_40_COLUMN_MAPPING_READY`**.

**KO:** NIST AMS 100-69의 positions 1..40 의미 순서를 outcome-independent하게 사전 고정했고, NIST NERDm/F22 SHA-256과 일치하는 네 registered ZIP 전체를 대상으로 1000 CSV / 4,748,352 non-empty rows의 구조를 값 비노출 방식으로 검증했다. 모든 row는 정확히 40 fields이고 numeric/NaN parse failure는 0이다. 따라서 headerless raw positions를 documented feature semantics에 deterministic하게 매핑하는 parser contract는 준비됐다.

F23은 numerical experiment 자체를 수행하지 않는다. 다음 단계는 별도 preregistration 하에 low-degree-of-freedom registered process/melt-pool ↔ XCT controlled experiment를 설계하는 것이다. 해당 실험은 F22의 `VIOLATED_LIMITED` pre-exposure를 명시적으로 상속하고, predictor/outcome/aggregation/split을 association 결과 열람 전에 고정해야 한다.

**EN:** The NIST AMS 100-69 semantic order for positions 1..40 was frozen independently of outcome analysis, and the complete set of four registered ZIPs matching NIST NERDm/F22 SHA-256 was structurally verified without emitting field values across 1000 CSVs / 4,748,352 non-empty rows. Every row contains exactly 40 fields with zero numeric/NaN parse failures. The parser contract deterministically mapping headerless raw positions to documented feature semantics is therefore ready.

F23 does not itself perform a numerical experiment. The next step is to separately preregister a low-degree-of-freedom registered process/melt-pool ↔ XCT controlled experiment. That experiment must explicitly inherit the F22 `VIOLATED_LIMITED` pre-exposure and freeze predictors, outcome, aggregation, and split structure before inspecting association results.
