# DEC-053 — Freeze F26 candidate set before qualification / F26 후보군 사전 고정

**KO:** D25 이후 동일 `mds2-3761` representation의 추가 feature/endpoint 탐색은 중단한다. 다음 mechanistic experiment 후보는 F26에서 사전에 고정한 네 source만 평가한다: A `mds2-3662`, B AMB2025-07, C `mds2-2525`, D `mds2-3842`. 후보 선정은 독립 condition, ≥3 physical repeats, deterministic condition→outcome pairing, outcome interpretability, authoritative source integrity, low-DOF experimentability의 6개 비가중 조건을 모두 PASS해야 한다. Outcome 수치나 association 결과를 보고 후보를 추가·교체하지 않는다.

**EN:** After D25, stop additional feature/endpoint exploration on the same `mds2-3761` representation. F26 evaluates only four prospectively frozen sources for the next mechanistic experiment: A `mds2-3662`, B AMB2025-07, C `mds2-2525`, and D `mds2-3842`. Selection requires PASS on all six unweighted dimensions: independent condition, ≥3 physical repeats, deterministic condition→outcome pairing, outcome interpretability, authoritative source integrity, and low-DOF experimentability. Do not add or replace candidates after inspecting outcome values or association results.
