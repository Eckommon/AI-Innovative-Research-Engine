# DEC-084 — F42 PASS; Authorize Separately Preregistered Path-Order-Only Benchmark
# DEC-084 — F42 PASS; 별도 사전등록 Path-Order-Only Benchmark 승인

## Decision / 결정

Finalize F42 as **`PASS_F42_SOURCE_GROUNDED_PATH_TRANSFER_READY`**.

Authorize the next step as a separately preregistered **AMBENCH-E43 — P01 Source-Grounded Path-Order-Only Thermal Benchmark**.

## Why path-only first / Path-only 우선 이유

F39/E40 showed that a synthetic third-actuator comparison can become non-identifiable before performance. F41/F42 now establish a genuinely distinct path intervention using public NIST process input. Therefore the path/order branch must demonstrate incremental value **by itself** before any multi-actuator combination is reconsidered.

## E43 execution authority / E43 실행 권한

E43 may compare only:
- nominal P01 source-run order `[1..39]`;
- frozen F41 risk order `[5,39,6,18,24,22,20,21,23,25,27,17,16,28,29,15,14,13,30,26,31,7,32,19,12,11,33,34,10,8,9,38,35,36,37,1,3,2,4]`.

Both inputs must use the exact F42 transfer mapping, domain, positive-row membership, 10 us spot duration, source-derived off-duration slots, common 600 W benchmark beam, material and output settings.

No power modulation or additional timing optimization may be added in E43.

## Numerical execution requirement / 수치 실행 요건

Before any custom performance, E43 must freeze:
- exact pinned runtime identity;
- numerical solidification timestep compatible with the 10 us transferred spot commands;
- exact `MP_width` spatial-field metric and materiality thresholds;
- runtime/resource HOLD rule with no post-failure resolution reduction.

No row-level statistical inference is permitted; each simulation is one deterministic benchmark outcome.

## Boundary / 경계

Even an E43 PASS would establish path-order incremental value only in the pinned semi-analytic 3DThesis transfer benchmark. It is not NIST physical outcome reproduction, scanner-kinematics validation, novelty proof or production readiness.

Incremental monetary cost remains `0 USD`; runtime/evaluation remains `SHARED-INTERNAL-CANDIDATE`.
