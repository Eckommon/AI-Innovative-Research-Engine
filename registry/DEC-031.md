# DEC-031 — Select `mds2-2525` for post-D12 external-validation feasibility
# DEC-031 — D12 이후 외부검증 feasibility 대상으로 `mds2-2525` 선택

**Decision / 결정:** Select NIST A-AMB2022-01 PDR `mds2-2525` as the highest-priority post-D12 external-validation asset and evaluate it first through `AMBENCH-F13` source/identity/time-alignment feasibility before any numerical external-validation experiment. / NIST A-AMB2022-01 `mds2-2525`를 D12 이후 최우선 외부검증 자산으로 선택하고 수치 외부검증 실험 전에 F13 source/identity/time-alignment feasibility를 수행한다.

**Rationale / 근거:** It combines time-resolved absorptance with simultaneous high-speed X-ray melt-pool measurements in material/experimental contexts independent of BP4, while current public evidence does not yet justify treating its repeat structure as a direct D12 replication asset. / BP4와 독립적인 재료·실험조건에서 time-resolved absorptance와 동시 X-ray melt-pool 측정을 제공하지만 공개 repeat 구조가 D12 직접복제로 충분한지는 아직 확립되지 않았다.

**Boundary / 경계:** No numerical outcome access or model fitting under F13. `COST-001`/`DEC-028` prior-approval rule remains mandatory.
