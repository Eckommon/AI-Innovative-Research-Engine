# DEC-191 — Authorize C-EU-F01 site-heat identity feasibility

## Decision / 결정

Authorize Issue #139 / C-EU-F01 as an outcome-blind source/access/identity gate using exactly one industrial identity family and one climate family:
- industrial identity: exact EEA `InspireSiteId` with official coordinates;
- climate family: ERA5-Land `2m temperature`.

## Rationale / 근거

The EEA public layer exposes exact site identities and point coordinates without requiring pollutant/outcome access. ERA5-Land officially provides a 0.1° hourly 2m-temperature point/time-series source and specifies nearest-grid-point semantics, while its ARCO programmatic route requires a CDS API key. F01 must therefore distinguish source/identity readiness from credential-limited climate-byte/grid-metadata access rather than bypass authentication.

## Boundary / 경계

- no pollutant/release/waste/energy/production or industrial-performance outcome access;
- no site temperature magnitudes persisted or summarized;
- no relationship/effect calculation;
- no fuzzy identity repair, invented grid origin, unofficial mirror or auth bypass;
- no post-support threshold or hazard-family rescue;
- incremental monetary cost remains 0 USD.
