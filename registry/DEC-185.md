# DEC-185 — Authorize US-MINE-N01 Hours-Ramp Design / US-MINE-N01 운영시간 급증 설계 승인

## Decision / 결정

**KO:** Issue #135 / US-MINE-N01에서 사고·부상 결과를 열기 전에 단 하나의 exposure family인 `ALL_SECTOR_OPERATOR_HOURS_RAMP_UP`을 고정하고, operator `HOURS_WORKED`만으로 exposure-only 매칭 식별성을 검증한다.

**EN:** For Issue #135 / US-MINE-N01, freeze exactly one exposure family, `ALL_SECTOR_OPERATOR_HOURS_RAMP_UP`, before opening any accident/injury outcome and test exposure-only matched-design identifiability using operator `HOURS_WORKED` only.

## Rationale / 근거

F01 established near-complete `HOURS_WORKED` structural support in both Coal and Metal/Nonmetal while preserving the official restriction that Metal/Nonmetal operators are not required to report production. Employee hours therefore provide the only currently authorized cross-sector operational-volume family that does not silently violate `PRODUCTION_SCOPE_RESTRICTED`.

F01은 Coal과 Metal/Nonmetal 모두에서 `HOURS_WORKED`의 거의 완전한 구조 지원을 확인했지만, Metal/Nonmetal 생산량은 의무보고가 아니므로 생산량 기반 national exposure는 허용되지 않는다. 따라서 operator-hours가 현재 승인 가능한 cross-sector operational-volume family이다.

## Boundaries / 경계

- N01 does not read the Accidents source.
- Injury outcome values and injury counts by exposure remain closed.
- Production magnitude is not used.
- Exposure thresholds, matching rules and minimum support are frozen before exposure-magnitude execution.
- No fallback/rescue after observing support.
- A N01 PASS is design identifiability only and carries no injury-effect or causal claim.
- Incremental monetary cost remains 0 USD.
