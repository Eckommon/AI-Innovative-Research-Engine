This establishes an identifiable path/order intervention candidate before performance.

## F42 authority / F42 권한

- exact P01 run membership and within-run point order;
- original 10 us command-row timing for source construction;
- unchanged F41 risk order;
- identical positive-power row count / laser-on duration between nominal and reordered cases;
- identical total laser-off transition-time budget;
- source-native run geometry without geometry/result-driven splitting or smoothing.

F42 may use explicit zero-power repositioning abstraction only if total source-derived laser-off time is preserved and the abstraction is fixed before any simulator performance.
