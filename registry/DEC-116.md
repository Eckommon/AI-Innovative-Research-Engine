# DEC-116 — Freeze CA-RAIL-E01 as a Single Extreme-Cold/Dwell Experiment
# DEC-116 — CA-RAIL-E01을 단일 극한저온/체류시간 실험으로 고정

## Decision / 결정

Preregister exactly one numerical descendant of CA-RAIL-F01:

**CA-RAIL-E01 — weekly extreme minimum temperature × intermodal terminal dwell**

Primary weather variable:
**ECCC daily Minimum Temperature (°C)**.

Weekly exposure:
**minimum daily Min Temp across the Monday–Sunday reporting week**, requiring 7/7 valid days.

Primary outcome:
**log1p weekly intermodal terminal dwell hours**.

Primary model:
carrier-terminal fixed effects + reporting-week fixed effects.

Primary inference:
one-way CR1 clustered by frozen ECCC Climate ID, using `t_(G-1)`.

Primary hypothesis:
**beta < 0**.

## Why this variable / 선정 이유

Extreme cold has a direct pre-outcome operational rationale in Canadian rail safety/operations. Selecting minimum temperature before values avoids multi-weather-variable search and avoids inventing a post-outcome threshold.

The official -25 °C winter restriction evidence is a mechanism/motivation reference only; E01 does **not** adopt -25 °C as its primary threshold.

## Prohibitions / 금지

Before the primary result is finalized, do not:
- test snow, precipitation, wind or gust as alternate primary exposures;
- choose a temperature threshold;
- search lag/lead effects;
- drop terminals because their coefficient looks weak;
- substitute another dwell measure or commodity;
- rank carriers/terminals.

## Execution authorization / 실행 승인

Authorize Stage A source/hash/completeness validation under the preregistration.

Stage B is authorized only if Stage A passes unchanged.

## Cost / 비용

Incremental monetary cost remains **0 USD**. Any potentially billable work requires explicit prior approval.
