# CLM-079 — Registered X4 CSVs are headerless and F22 incurred limited numerical pre-exposure
# CLM-079 — registered X4 CSV는 headerless이며 F22에서 제한적 numerical 사전노출 발생

**KO:** F22 Part 1 schema workflow가 CSV 첫 줄을 textual header로 가정했으나 실제 파일은 headerless였다. 그 결과 Part 1 CSV들의 첫 줄이 header 확인 과정에서 읽혔고 최초 sanitized result에는 첫 CSV의 numerical row가 header처럼 기록됐다. Current-facing result에서는 해당 값들을 제거했으며 `AMENDMENT-01`에 범위와 영향이 기록되어 있다. 따라서 `NEW_REGISTERED_X4_NUMERICAL_OUTCOME_BLIND = VIOLATED_LIMITED`이며, 이후 분석은 pristine outcome-blind라고 주장할 수 없다. 이 사건은 SHA-256/ZIP/layer-filename evidence를 무효화하지 않는다.

**EN:** The F22 Part 1 schema workflow assumed that each CSV began with a textual header, but the files are headerless. As a result, first lines from the Part 1 CSVs were read during the attempted header check and the initial sanitized result persisted the first CSV's numerical row as if it were a header. The current-facing result has removed those values and `AMENDMENT-01` records the scope and consequence. Therefore `NEW_REGISTERED_X4_NUMERICAL_OUTCOME_BLIND = VIOLATED_LIMITED`; later analysis cannot claim pristine outcome blindness. This event does not invalidate the SHA-256, ZIP, or layer-filename evidence.
