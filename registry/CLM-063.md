# CLM-063 — Bounded X16 representation is practically smaller than raw MPM
# CLM-063 — X16 bounded representation은 raw MPM보다 실용적으로 작다

**Claim / 주장**

NIST X16 current public metadata and metrics support a bounded future representation using only `OverhangX16_ImageHistograms.xlsx`, `DAQ_L101-L125.zip`, and `XYPT_L101-L125.zip`: the XCT workbook is about 193.26 KB, the selected DAQ group about 482.12 MB, and the selected XYPT group about 157.62 MB, while 25-layer MPM sources are multi-GB. / NIST X16 현행 공개 metadata·metrics는 XCT histogram workbook + 중앙 25-layer DAQ/XYPT만 사용하는 bounded representation이 raw MPM 전체보다 훨씬 작은 실용 경로임을 지지한다.

**Evidence / 근거**
- current NIST/Data.gov metrics for `mds2-2514` and `mds2-2309`;
- `research/AMBENCH-F18/README.md`;
- `research/AMBENCH-F18/RESULT.md`.

**Boundary / 경계**
This is source-scale feasibility only, not evidence of predictive or physical-outcome usefulness. / source 규모 feasibility이며 예측·물리 outcome 유용성 근거가 아니다.
