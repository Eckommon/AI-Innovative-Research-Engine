as the next mission branch.

## Why selected / 선정 이유

The branch currently provides the strongest combination of:
- a directly observed operational bottleneck outcome (vessel berth/dwell time and call support);
- cross-agency relationship value (BTS/USCG/USACE-derived port performance × NOAA weather events);
- falsifiable downstream design potential;
- practical logistics/capacity/throughput relevance;
- current public official-source access with no paid service requirement;
- independence from the UK-GRID, KR-PORT credential, and AMBENCH P01 blocked routes.

Current official-source refresh on 2026-09-03 confirmed the BTS Port Performance program, BTS vessel-berthing technical documentation/public data surface, and NOAA Storm Events bulk distribution remain available.

## F01 authorization boundary / F01 승인 경계

Authorize only a source-semantic/join-feasibility gate.

F01 may determine:
1. whether a stable official BTS row-level/tabular berthing export/API is available;
2. temporal grain, port/vessel identities, dwell metrics and call-count support;
3. deterministic official port geographic anchoring;
4. NOAA Storm Events temporal/geographic join semantics;
5. a bounded common coverage interval;
6. duplicate/revision and snapshot/hash rules.

If stable official tabular access or deterministic geography is not available without dashboard scraping/manual arbitrariness, F01 must HOLD/PARTIAL and return to Stage 0 rather than create a scraping/tooling descendant.
