# DEC-089 — Authorize F44 Surface-Only MP_Stats Representation Equivalence Gate
# DEC-089 — F44 Surface-Only MP_Stats 표현 동등성 Gate 승인

## Decision / 결정

Authorize AMBENCH-F44 as a separate zero-cost representation-equivalence gate after E43's runtime HOLD.

F44 is not an E43 rescue. It may not change or reinterpret E43's frozen experiment or claim that path ordering works. It may only test whether a `Z Num=1` top-surface representation preserves the top-surface `MP_width` field on the preregistered non-comparative source-native calibration prefix.

## Frozen scope / 고정 범위

- source identity remains NIST `mds2-2507` v1.0.1 and checksum-frozen `RHF_Command.zip`;
- calibration source prefix is positive-power runs 1–6 in original P01 order, with exact leading-off and first five inter-run gaps, stopped at end of run 6;
- pinned 3DThesis commit remains `2de7fc6d8cfa5de78b111df97b1a4d9156a8cf60`;
- `Solidification / Surface / Timestep=1e-5 s` remains fixed;
- X/Y frame and resolution remain exactly E43/F42;
- only Z representation differs: FULL41 vs TOP1 `Num 1`;
- both cases use the same calibration Path bytes, material, beam, output and settings;
- FULL41 and TOP1 each have 180 s hard cap; workflow cap 10 min;
- no paid compute and no cap extension are authorized.

## Frozen equivalence contract / 고정 동등성 계약

Primary comparison is the entire 8,181-coordinate top-surface `MP_width` field, including zeros.

PASS requires:
- valid source/build/runtime/schema integrity;
- exact common coordinate set of 8,181 top-surface points;
- coordinate-wise `MP_width` max absolute difference <= `1e-12 m`;
- identical positive-width coordinate support;
- coordinate-wise `MP_length` max absolute difference <= `1e-12 m` for full MP_Stats PASS.

`MP_depth` is excluded because TOP1 intentionally removes subsurface representation.

No post-result tolerance changes, ROI filters or positive-only primary matching are allowed.

## Frozen gates / 고정 gate

- `PASS_F44_SURFACE_ONLY_MPSTATS_EQUIVALENT`
- `PARTIAL_F44_MPWIDTH_ONLY_EQUIVALENT`
- `REJECT_F44_SURFACE_ONLY_REPRESENTATION`
- `HOLD_F44_RUNTIME_OR_INTEGRITY`

## Next authority / 다음 권한

A F44 PASS or PARTIAL does not itself authorize a full-P01 TOP1 path-order experiment. A separate durable decision must evaluate runtime feasibility and claim-transfer integrity first.

## Cost / 비용

Incremental monetary cost remains `0 USD`. Billable compute requires explicit prior user approval.
