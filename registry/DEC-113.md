# DEC-113 — Select WAVE3-GEO-D01 After JP-PORT-E01 PASS
# DEC-113 — JP-PORT-E01 PASS 이후 WAVE3-GEO-D01 선정

## Decision / 결정

Select:

**`WAVE3-GEO-D01 — Canada / Australia / OECD-World Bank Relationship Candidate Discovery`**

as the single immediate next bounded gate.

## Rationale / 근거

The portfolio now contains several reusable PASS/validated assets, but immediate same-branch descendants have lower marginal information value or known access/construct constraints.

Wave-3 geographic expansion offers:
- new country/institution structures;
- currently accessible official APIs/catalogs;
- higher diversification;
- potential new independent-unit relationships;
- low sunk-cost screening before any experiment.

Current accessibility supports a minimum-operable D01:
- Canada public CKAN read access;
- Statistics Canada web data service;
- Australia public catalog/resource interfaces subject to per-resource access qualification;
- OECD free SDMX API;
- World Bank V2 API without authentication.

## Boundary / 경계

D01 is discovery, not a broad catalog build.

It must produce a small ranked candidate set and select at most one F01.

Do not automatically continue Japan, US mineral, US grid, UK grid or EU-site branches without a new portfolio selection.

## Cost / 비용

Incremental monetary cost remains **0 USD**. Any potentially billable work requires explicit prior approval.
