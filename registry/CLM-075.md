# CLM-075 — X16 empty/solid threshold is part-specific / X16 empty·solid threshold는 part별 상이

**KO:** NIST X16 XCT Data Description은 16개 voxel histogram이 nominally bimodal(empty/solid)이지만 각 peak의 mean과 variance가 달라, empty와 solid를 구분하는 threshold는 각 part 데이터에 대해 별도로 선택해야 한다고 명시한다. 따라서 모든 16개 part에 하나의 공통 digital-level threshold를 적용하는 것은 authoritative semantics가 지지하지 않는다.

**EN:** The NIST X16 XCT Data Description states that the sixteen voxel histograms are nominally bimodal (empty/solid), but their peak means and variances differ, requiring the empty/solid threshold to be chosen uniquely for each part. A single common digital-level threshold across all sixteen parts is therefore not supported by the authoritative semantics.
