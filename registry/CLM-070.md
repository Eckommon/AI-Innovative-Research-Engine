# CLM-070 — Current X16 workbook public identity before F20 retrieval / F20 회수 전 X16 workbook 공개 identity

**KO:** F20 시작 시점의 current Data.gov/NIST metadata는 `mds2-2514`의 `OverhangX16_ImageHistograms.xlsx`와 동명 `.sha256` sidecar의 공식 `data.nist.gov/od/ds/ark:/88434/mds2-2514/...` downloadURL을 제공하며, NIST metrics는 workbook 크기를 약 193.26 KB로 보고한다. 이는 public component identity를 지지하지만 checksum 값 또는 workbook byte integrity 자체를 증명하지는 않는다.

**EN:** At F20 start, current Data.gov/NIST metadata exposes official `data.nist.gov/od/ds/ark:/88434/mds2-2514/...` download URLs for `OverhangX16_ImageHistograms.xlsx` and its same-name `.sha256` sidecar, while NIST metrics reports the workbook size at about 193.26 KB. This supports public component identity but does not itself establish the checksum value or workbook-byte integrity.
