# DEC-024 — Select Same-BP4 Coupling↔Confocal Feasibility / 동일 BP4 coupling↔confocal feasibility 선택

**KO:** D06와 E09 이후의 다음 공식 후보로 `BP4 dynamic coupling temporal dynamics → same-BP4 laser-scanning-confocal 3D topography` 관계를 선택하되, 현재 exact public confocal publication/manifest가 확립되지 않았으므로 곧바로 모델링하지 않고 `AMBENCH-F10` source/identity feasibility gate를 먼저 수행한다.

**EN:** After D06 and E09, select the `BP4 dynamic-coupling temporal dynamics → same-BP4 laser-scanning-confocal 3D topography` relationship as the highest-leverage next candidate, but because an exact public confocal publication/manifest has not yet been established, perform the `AMBENCH-F10` source/identity feasibility gate before any modeling.

## Rationale / 근거

1. D06 showed the existing BP1 thermal representation was overwhelmingly process-case dominated and low-dimensional.
2. E09 showed that coupling magnitude changed but the seven-case VED rank did not, so rank-only case aggregation discarded potentially useful temporal/magnitude information.
3. Official AMB2022-03 documentation states that BP4 is the 3×7 dynamic-coupling single-track plate and that coupling specimens were subsequently measured using laser scanning confocal microscopy for complete 3D surface profiles.
4. If an exact public BP4 confocal source and deterministic track IDs exist, the relationship can remove the BP1↔BP4 cross-specimen limitation and support same-specimen track/repeat evidence.
5. Current direct-data guidance and targeted public searches did not establish the exact public version-identifiable confocal publication, so source readiness is the controlling blocker.

## Boundaries / 경계

- F10 is metadata/identity feasibility only; no confocal numerical outcome access.
- `NEW_CONFOCAL_OUTCOME_BLIND = YES`.
- `FULL_OUTCOME_BLIND = NO — COUPLING_PREOBSERVED` because E09 already observed BP4 coupling values.
- no BP1 optical substitution;
- no inferred same-track identity from matching case labels;
- `COST-001` and `RAW-001` remain mandatory.

## Fallback / 대안

If F10 ends in HOLD, the next preferred fallback is a separately preregistered **within-BP4 coupling temporal-information diagnostic** that tests repeat-vs-case variance and temporal effective dimension without claiming ex-situ physical utility.

**Decision state:** `ACTIVE — F10 SELECTED / EXECUTION NOT YET COMPLETED`.
