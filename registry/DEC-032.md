# DEC-032 — Finalize AMBENCH-F13 as PARTIAL same-experiment external-validation ready
# DEC-032 — AMBENCH-F13을 PARTIAL same-experiment 외부검증 준비로 확정

**Decision / 결정:** Finalize `AMBENCH-F13` as **`PARTIAL_SAME_EXPERIMENT_EXTERNAL_VALIDATION_READY`**. / F13을 해당 PARTIAL 상태로 확정한다.

**Rationale / 근거:** `mds2-2525` provides authoritative checksum-bearing public components, experimental independence from BP4, simultaneous absorptance/X-ray provenance, and a stationary-Al time-dependent absorption ↔ time-dependent width branch. However, repeat-resolved public event identity adequate for direct replication of D12's repeat-level result is not verified.

**Consequence / 후속:** Do not claim D12 repeat generalization. The next eligible experiment is a separately preregistered low-degree-of-freedom external physical-validation test on the A-AMB stationary-Al branch. Numerical outcome access is prohibited until that experiment freezes alignment, normalization, descriptors, endpoint transforms, statistics, and gate.

**Integrity note / 무결성:** F13 `AMENDMENT-01` corrects outcome-blindness to `NO — PUBLICATION_LEVEL_AGGREGATES_PREOBSERVED`; the preobserved publication aggregates were not used in the F13 gate.

**Cost:** `COST-001` + `DEC-028` remain mandatory; no potentially billable action without explicit prior approval.
