The frozen Stage-A gate required:
- >=120 qualified origin AirportIDs;
- >=120 represented NOAA station identities;
- each qualified airport >=330 usable assigned precipitation days;
- each month >=20 usable assigned days;
- no manual station repair;
- no delay-magnitude exposure.

- 255 qualified airports;
- 255 represented NOAA stations;
- 92,818 usable airport-date weather keys;
- 0 assignment gaps;
- 0 ambiguous station assignments;
- 0 NOAA fetch failures;
- 0 DailyPrecipitation-column failures;
- 0 station-year hash drift relative to F01 DATE-support snapshot.

Eight airports fail the prospectively frozen weather-quality rule and are excluded without reference to delay outcomes.

## Stage B authorization / Stage B 승인

Stage B may now load BTS DepDelayMinutes **only** under the model and denominator already frozen in DEC-124 / research/US-AIR-E01/README.md.

Before any coefficient is interpreted, Stage B must:
1. verify all twelve BTS 2025 PREZIP SHA-256 values against the F01 frozen manifest before parsing any delay magnitude;
2. use only Stage-A qualified airport-dates with usable primary precipitation;
3. retain >=100 airports and >=30,000 airport-date observations;
4. execute exactly the frozen primary model and gate;
5. run prespecified sensitivities only after the primary result.

No weather-variable, threshold, lag, outcome, airport or carrier search is authorized.
