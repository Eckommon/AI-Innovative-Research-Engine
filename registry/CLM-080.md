# CLM-080 — AMS 100-69 defines the positional 40-column registered schema / AMS 100-69은 위치 기반 40열 registered schema를 정의한다

**KO:** NIST AMS 100-69 Section 3.2는 `mds2-3761`의 각 registered CSV가 40 columns와 multiple rows로 구성되며 각 row가 associated features를 가진 하나의 measured point라고 정의한다. Tables 1–3은 positions 1..40의 이름, 단위 및 정의를 명시한다. 따라서 headerless raw CSV의 positions 1..40은 `research/AMBENCH-F23/README.md`의 frozen positional map에 따라 결정론적으로 해석할 수 있다.

**EN:** NIST AMS 100-69 Section 3.2 defines each registered CSV in `mds2-3761` as 40 columns and multiple rows, with each row representing one measured point with associated features. Tables 1–3 explicitly define the names, units and definitions for positions 1..40. Therefore the positions in the headerless raw CSVs can be deterministically interpreted using the frozen positional map in `research/AMBENCH-F23/README.md`.
