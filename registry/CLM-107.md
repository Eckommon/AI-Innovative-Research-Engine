# CLM-107 — E33 Equivalent-Length Prior-History Association
# CLM-107 — E33 동등 길이 Prior-History 연관

## Claim / 주장
Within NIST `mds2-3662` Set 2, after pairing converging `C(t)` with diverging `D(19−t)` as **equivalent programmed track lengths** and using the preregistered prior-track contrast `h_t = 2t−19`, the top-surface maximum melt-pool-width contrast is perfectly monotonic in the frozen primary analysis:

- valid blocks: `18/18`;
- Spearman `rho = +1.0`;
- deterministic two-sided 100,000-permutation add-one `p = 9.999900001e-06`;
- Operator 1 sensitivity `rho = +0.985524341588`;
- Operator 2 sensitivity `rho = +1.0`;
- primary gate: `PASS_E33_GEOMETRY_MATCHED_HISTORY_ASSOCIATION`.

## Boundary / 경계
This supports a strong association between opposite prior-scan histories and melt-pool width **within this IN625 beam-on-plate rapid-turnaround design** when programmed track length is reverse-matched.

It does not establish:
- same-XY-location control;
- a causal effect isolated from all spatial/systematic design factors;
- same-construct replication of AMB2025-07 turnaround time;
- pristine outcome-blind discovery, because publication-level outcomes were exposed after preregistration but before raw workbook execution.

Raw workbook cells were not committed; source checksum and frozen analysis contract are preserved in `RESULT.md`.
