# DEC-064 — Preregister F31 alternate pad-geometry source/identity gate / F31 대체 pad-geometry source·identity gate 사전등록

## Decision / 결정
Preregister `AMBENCH-F31` as a source/design-only qualification gate before any alternate-geometry numerical outcome inspection.
