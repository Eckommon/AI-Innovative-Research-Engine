# DEC-100 — Close UK-GRID-F02 PASS and Select SCOTEX for the Single Numerical Experiment
# DEC-100 — UK-GRID-F02 PASS 종결 및 단일 수치 실험 대상으로 SCOTEX 선정

## Decision / 결정

1. Close `UK-GRID-F02` as **`PASS_UK_GRID_BOUNDARY_IDENTITY_READY`**.
2. Preserve `CLM-121` as a bounded source-identity claim.
3. Select **`SCOTEX` only** for the one numerical experiment allowed under `DEC-098 / DEC-099`.
4. The experiment must be fully preregistered before any selected 2026 observation-level `Limit (MW)`, `Flow (MW)` or `Daily Cost (GBP)` value is retrieved.

## Outcome-blind selection rationale / 결과 비사용 선정 근거

The selection is based only on official NESO source semantics and F02 eligibility, not on observed numerical results.

NESO identifies `SCOTEX` with the Anglo-Scottish **B6 — SP Transmission to NGET** boundary. Current NESO planning material states that:
- expected Scottish power transfer is predominantly north-to-south;
- additional Scottish generation, especially onshore/offshore wind, increases Scotland→England transfer requirements;
- B6 base capability is currently described as limited to 6.7 GW by a thermal constraint on the Harker–Moffat 400 kV circuit;
- recent NESO boundary-flow work explicitly names `SCOTEX (B6)` among the constrained Scotland/northern-England boundaries where flow volatility and constraint cost are operationally important.

This gives `SCOTEX` a clearer source-defined physical and operational mechanism than selecting a boundary based on unobserved result magnitude.

## Future construct / 향후 검증 구조

Prospective relationship:

`SCOTEX day-ahead boundary stress → SCOTEX realized daily thermal-constraint cost`.

`Day Ahead Constraint Flows and Limits` defines:
- `Limit (MW)` as the maximum amount of power that can flow through a constraint boundary;
- `Flow (MW)` as a day-ahead forecast based on next-day wind forecast, generation dispatch and demand forecast.

`Thermal Constraint Costs Data 26-27` defines `Daily Cost (GBP)` as daily spend for the named constraint.

## Scientific boundary / 과학적 경계

The planned experiment tests **predictive/operational association**, not causality.

Although NESO's B6 planning description includes a thermal capability constraint, the published day-ahead operational limit can reflect system operating conditions and must not be represented as a pure immutable thermal rating. A positive result therefore supports an operational boundary-stress indicator, not a causal proof that one circuit rating alone caused cost.

## Stop rule / 중단 규칙

If preregistered source/cardinality/maturity integrity cannot be satisfied without changing the design after observing numerical outcomes, stop as HOLD and return to Stage 0. No retuning, boundary substitution, or post-hoc date-window change is authorized.

After the single numerical experiment, mandatory Stage 0 Mission-ROI portfolio return applies regardless of PASS/PARTIAL/NO.

## Cost / 비용

Incremental monetary cost remains **0 USD**.
