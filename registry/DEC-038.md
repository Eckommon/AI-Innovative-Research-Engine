# DEC-038 — Finalize F16 as PARTIAL_PUBLIC_ENDPOINT_READY
# DEC-038 — F16을 PARTIAL_PUBLIC_ENDPOINT_READY로 확정

**Decision / 결정:** Finalize `AMBENCH-F16` as **`PARTIAL_PUBLIC_ENDPOINT_READY`**. Preserve `mds2-3761` as a high-value registered process–structure asset, but do not preregister numerical modeling until exact data-bearing version lineage plus immutable component integrity and checksum-verifiable authoritative bytes are established.

`AMBENCH-F16`을 **`PARTIAL_PUBLIC_ENDPOINT_READY`**로 확정한다. `mds2-3761`를 고가치 registered process–structure 자산으로 보존하되, exact data-bearing version 계보·immutable component integrity·checksum-verifiable authoritative bytes가 확립되기 전 numerical modeling을 사전등록하지 않는다.

**Next direction / 다음 방향:** Avoid repeated blind retries against the same failing endpoint. Prefer a targeted official NIST/PDR version/checksum metadata route; if that remains unavailable under zero-cost constraints, triage another authoritative external process–structure dataset.

**Cost:** no paid/potentially paid route used; prior explicit user approval remains mandatory before any such action.
