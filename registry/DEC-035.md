# DEC-035 — Select NIST `mds2-3761` as post-E14 external-validation feasibility target
# DEC-035 — E14 이후 외부검증 feasibility 대상으로 NIST `mds2-3761` 선택

## Decision / 결정

Preserve E14 at `HOLD_SOURCE_INTEGRITY` without redesign or repeated uncontrolled retrieval attempts, and select NIST `mds2-3761` fully registered in-situ/ex-situ X4 dataset for the next source/identity feasibility gate `AMBENCH-F15`.

E14를 재설계하거나 무제한 retrieval 재시도하지 않고 `HOLD_SOURCE_INTEGRITY`로 보존하며, 다음 source/identity feasibility gate `AMBENCH-F15` 대상으로 NIST `mds2-3761` fully registered in-situ/ex-situ X4 dataset을 선택한다.

## Rationale / 근거

NIST documentation establishes four nominally identical parts, 250 layers per part, registered point-level numerical data, commanded/real laser variables, in-situ melt-pool features, layerwise optical features, and ex-situ XCT voxel values in a shared machine-coordinate framework. This is a stronger next external process–structure validation candidate than adding feature capacity to the existing BP4 dataset.

## Cost boundary / 비용 경계

No paid or potentially paid retrieval/compute is authorized. `COST-001` + `DEC-028` apply.
