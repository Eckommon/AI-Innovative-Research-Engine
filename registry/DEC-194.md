# DEC-194 — Authorize US-FDA-MD-F01 source/schema/FEI feasibility

## Decision / 결정

Authorize exactly one outcome-blind `US-FDA-MD-F01` gate under Issue #141. The gate may inspect FDA inspection **baseline identity/classification** data and Device Recall **structural identity/date** data only to establish source/schema/FEI feasibility.

## Frozen design boundary / 고정 경계

- exact facility key: FDA FEI;
- structural inspection row key: `(FEI, inspection end date, FDA-native Project Area-or-equivalent)`;
- final inspection classification allowed: NAI/VAI/OAI;
- medical-device cohort must come from FDA-native inspection-source semantics only;
- public inspection database incompleteness is preserved and future inference, if any, is bounded to the disclosed inspected cohort;
- recall-side structural fields may be used for aggregate exact FEI overlap/fingerprints only;
- no recall incidence/membership stratification by inspection class and no relationship computation;
- no unofficial mirror, credential bypass or paid source.

## Access-aware dispositions / 접근 판정

Full PASS requires actual official inspection bytes and all frozen support thresholds. PARTIAL is allowed only if FDA documentation/openFDA semantics are ready and **official inspection-byte access is the sole blocker** because the advertised public download is unavailable while remaining official API access requires credentials. Any deeper schema/identity failure is HOLD.

Incremental monetary cost remains 0 USD.
