# DEC-051 — Finalize E24 as NO_MATERIAL and prohibit feature-fishing escalation / E24를 NO_MATERIAL로 종료하고 feature-fishing escalation 금지

**Decision / 결정:** `AMBENCH-E24` final gate = **`NO_MATERIAL_E24_ASSOCIATION`**.

**KO:** Primary partial R² `0.019321`은 사전등록 materiality threshold `0.05` 미만이다. permutation p `0.007900`, locality criterion PASS, t80/t120 directional consistency가 존재하더라도 materiality gate를 소급 완화하지 않는다. 동일 dataset에서 predictor/endpoint를 임의로 추가하거나 nonlinear/high-capacity model로 구조를 구제하는 시도는 금지한다.

다음 highest-leverage 작업은 feature search가 아니라 **part/block dominance와 sign reversal의 variance structure를 사전등록된 diagnostic으로 분해**하는 것이다. 그 diagnostic 이후에만 새로운 independent experiment의 필요성과 설계를 판단한다.

**EN:** The primary partial R² `0.019321` is below the preregistered materiality threshold `0.05`. The gate is not weakened post hoc despite permutation p `0.007900`, a passing locality criterion, and directionally consistent t80/t120 sensitivities. Do not rescue the same dataset by adding arbitrary predictors/endpoints or escalating to nonlinear/high-capacity models.

The next highest-leverage work is a preregistered diagnostic decomposition of part/block dominance and the sign reversal, not feature search. Only after that diagnostic should the project decide whether a genuinely new independent experiment is justified.
